# Peta Komponen Komputer

Aplikasi web interaktif untuk menjelaskan fungsi komponen komputer. Dibuat sebagai project UTS mata kuliah Arsitektur dan Organisasi Komputer.

## Fitur

- **Jelajahi**: fungsi, analogi, contoh, dan fakta untuk 9 komponen (CPU, RAM, motherboard, storage, GPU, PSU, pendingin, input, output).
- **Alur kerja**: simulasi 7 langkah dari menekan tombol power sampai gambar tampil di monitor.
- **Kuis**: 6 soal pilihan ganda dengan penjelasan jawaban.

## Cara menjalankan

Buka `index.html` di browser. Tidak perlu instalasi.
